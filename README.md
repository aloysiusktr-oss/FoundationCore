# FoundationCore

> *"Every great world begins with a single line of code."*

FoundationCore is the engine behind **Project Foundation**, a community-driven SkyBlock server built with long-term architecture, fairness, and unforgettable player experiences at its core.

Project Foundation is more than a Minecraft server.

It is the proving ground for the systems, philosophy, and technology that will eventually power **Project Ascension**, a living MMORPG where players permanently shape the world's history.

---

# Vision

We believe Minecraft servers can become more than games.

They can become worlds that players remember years later because of the stories they created inside them.

Every feature we build must move us closer to that goal.

---

# Our Promise

We will never add a feature simply because it is popular.

Every mechanic must answer one question:

> **Will players still be telling stories about this twenty years from now?**

If the answer is no, we rethink it.

Player trust will always be worth more than short-term growth.

---

# Core Philosophy

## Frameworks Before Features

Reusable architecture is more valuable than isolated mechanics.

Every new system should make future development easier.

---

## Player Trust Comes First

Respect the player's time.

Respect the player's effort.

Never sell power.

Reward creativity, mastery, cooperation and exploration.

---

## Small First. Scale Later.

Build one polished system.

Test it.

Refine it.

Expand it.

---

## The Three-Hour Rule

A brand-new player should enjoy their first three hours without needing:

- a wiki
- YouTube guide
- Discord explanation
- external tools

The game should naturally teach itself.

---

## The North Star Question

Before any feature is implemented we ask:

> **Does this make the world feel more alive, more memorable, or more player-driven?**

If it doesn't...

We redesign it.
