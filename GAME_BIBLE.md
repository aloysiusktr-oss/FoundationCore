# Project Foundation Game Bible

## Purpose

Project Foundation is a fair, community-first SkyBlock server designed to build experience, community, and reusable systems for Project Ascension.

## Core Principles

### No Pay-To-Win

Players should never gain power because they spent money.

### Three-Hour Rule

A new player should enjoy their first three hours without needing a wiki, guide, Discord explanation, or YouTube tutorial.

### Frameworks Before Features

Build reusable systems before isolated mechanics.

### Small First, Then Scale

One polished system is better than ten broken systems.

### Player Trust Comes First

Every system should respect the player's time, effort, and progression.

## North Star Question

Does this make the server feel more alive, more memorable, or more player-driven?
