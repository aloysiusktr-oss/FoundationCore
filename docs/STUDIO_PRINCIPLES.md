# Studio Principles

## Purpose

Project Foundation exists to build a fair SkyBlock server, grow a community, and develop the tools, workflow, and experience needed for Project Ascension.

---

## Core Beliefs

### Player Trust Comes First

We do not sell power.

We do not manipulate players with unfair monetization.

We respect time, effort, creativity, and mastery.

---

### Build Small, Build Properly

One polished system is better than ten broken systems.

Every feature must be tested before we move on.

---

### Frameworks Before Features

If a framework will make several future systems easier, we build the framework first.

---

### Documentation Is Development

If a feature is not documented, it is not finished.

---

### No Shortcuts That Create Future Debt

Speed matters, but not at the cost of maintainability.

We would rather spend one hour doing something properly than ten hours fixing avoidable mistakes later.

---

## The North Star Question

Before we build anything, we ask:

> Does this make the server feel more alive, more memorable, or more player-driven?

If the answer is no, we rethink it.

---

## Long-Term Vision

Project Foundation is the stepping stone.

Project Ascension is the destination.

Every system should be built with enough care that it may one day help power both.
